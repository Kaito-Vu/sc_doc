# i18n policy — English and Vietnamese only

**Trạng thái:** Đã áp dụng  
**Ngôn ngữ hỗ trợ:** `en-US` (mặc định), `vi-VN`  
**Đã bỏ:** de-DE, es-ES, fr-FR, it-IT, ja-JP, ko-KR, nl-NL, pt-BR, ru-RU, uk-UA, zh-CN

---

## 1. Nguồn sự thật

```text
apps/client/public/locales/en-US/translation.json   # source of truth
apps/client/public/locales/vi-VN/translation.json   # bản dịch tiếng Việt
```

Hai file hiện có **cùng 2175 key**, không thiếu ở cả hai phía.

Quy ước:
- Key là chuỗi tiếng Anh dùng trực tiếp trong `t("...")`.
- Giá trị en-US = key.
- Giá trị vi-VN là bản dịch; thuật ngữ kỹ thuật/proper noun có thể giữ nguyên tiếng Anh.
- Không thêm locale mới nếu chưa cập nhật `lib/locales.ts`, `i18n.ts`, server `SUPPORTED_LOCALES` và language picker.

---

## 2. Danh sách locale tập trung

`apps/client/src/lib/locales.ts`:

```ts
export const SUPPORTED_LOCALES = ["en-US", "vi-VN"] as const;
export const DEFAULT_LOCALE = "en-US";
export const LOCALE_OPTIONS = [
  { value: "en-US", label: "English (US)" },
  { value: "vi-VN", label: "Tiếng Việt (Vietnamese)" },
];
export function normalizeLocale(value?: string | null): SupportedLocale;
```

`normalizeLocale` xử lý:
- `"en"` → `"en-US"`.
- Giá trị cũ không còn hỗ trợ (ví dụ `"de-DE"`) → `"en-US"`.

Được dùng ở:
- `i18n.ts` (`supportedLngs`)
- `account-language.tsx`
- `workspace-locale/use-workspace-locale.ts`
- `user-provider.tsx`
- `date-locale.ts`

---

## 3. Server

`apps/server/src/ee/workspace-locale/locales.ts`:

```ts
export const SUPPORTED_LOCALES = ['en-US', 'vi-VN'];
```

`UpdateUserDto.locale` chỉ chấp nhận `en-US` hoặc `vi-VN`. Workspace language setting dùng cùng danh sách.

Migration `20261020T000001-locale-en-vi-only` chuẩn hóa dữ liệu cũ:
- `users.locale` ngoài `en-US`/`vi-VN` → `en-US`.
- `workspaces.settings.defaultLocale` ngoài `en-US`/`vi-VN` → `en-US`.

Client cũng chuẩn hóa tại runtime qua `normalizeLocale` để an toàn trước dữ liệu cache.

---

## 4. UI

- Account → Preferences → Language chỉ còn English (US) và Tiếng Việt.
- Workspace → Default language chỉ còn hai lựa chọn.
- Khi admin bật “Force language”, mọi người dùng thấy ngôn ngữ mặc định; nếu giá trị cũ không hợp lệ, fallback `en-US`.
- `document.documentElement.lang` lấy từ i18n resolved language.

## 5. Crowdin

`crowdin.yml` chỉ xuất bản dịch Việt Nam:

```yaml
translation: /apps/client/public/locales/vi-VN/%original_file_name%
```

---

## 6. Thêm chuỗi mới

1. Thêm key vào `en-US/translation.json` (value = key).
2. Thêm key tương ứng vào `vi-VN/translation.json`.
3. Dùng `t("Key")` trong component.
4. Kiểm tra parity trước khi commit:
   - key count hai file bằng nhau.
   - không có key thiếu ở một phía.
